## Contents

| File | Description | Figure in the paper |
|---|---|---|
| `pdf.nb` | Probability density function | Fig. X |
| `cdf.nb` | Cumulative distribution function | Fig. X |
| `outage_probability.nb` | Outage probability | Fig. X |
| `aser.nb` | Average symbol error rate | Fig. X |
| `MonteCarlo-OP-ASER.nb` | Monte Carlo simulation of the outage probability and the average symbol error rate | Figs. X and X |

The first four notebooks implement the analytical expressions of the paper
(Eqs. X–X) and generate the corresponding figures.

The simulation points shown in the outage probability and average symbol error
rate figures are generated by `MonteCarlo-OP-ASER.nb`. The values it produces
are included in `outage_probability.nb` and `aser.nb`, so the figures can be
plotted without rerunning the simulation.

## Requirements

- Wolfram Mathematica [version, e.g. 13.3]

## Usage

1. To plot the figures, open the corresponding notebook and evaluate all cells
   (*Evaluation → Evaluate Notebook*).
2. To regenerate the simulation points, evaluate `MonteCarlo-OP-ASER.nb` and
   replace the simulation values in `outage_probability.nb` and `aser.nb` with
   the new output.
