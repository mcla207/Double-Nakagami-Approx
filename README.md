# Highly Accurate Approximations for the Sum of Double-Nakagami-m Envelopes

[![DOI](https://zenodo.org/badge/1447351646.svg)](https://doi.org/10.5281/zenodo.23989968)

Code accompanying the article:

> [Maria Luna Alvarado, Lenin Patricio Jimenez Jimenez, Gustavo Fraidenraich, Michel Daoud Yacoub], "[Highly Accurate Approximations for the Sum of Double-Nakagami-m Envelopes]," *Proc. XLI Brazilian Symp. Telecommun. Signal Process*, pp. 1-5, 2023.
> DOI: [10.14209/sbrt.2023.1570923751](https://doi.org/10.14209/sbrt.2023.1570923751)

## Contents

| File | Description | Figure in the paper |
|---|---|---|
| `PDF-plot.nb` | Probability density function | Fig. 1 |
| `CDF-plot.nb` | Cumulative distribution function | Fig. 2 |
| `OP-plot.nb` | Outage probability | Fig. 3 |
| `ASER-plot.nb` | Average symbol error rate | Fig. 4 |
| `MonteCarlo-OP-ASER.nb` | Monte Carlo simulation of the outage probability and the average symbol error rate | Figs. 3 and 4 |

The first four notebooks implement the analytical expressions of the paper
(Eqs. 1-4) and generate the corresponding figures.

The simulation points shown in the outage probability and average symbol error
rate figures are generated by `MonteCarlo-OP-ASER.nb`. The values it produces
are included in `OP-plot.nb` and `ASER-plot.nb`, so the figures can be
plotted without rerunning the simulation.

## Requirements

- Wolfram Mathematica [version, 12]

## Usage

1. To plot the figures, open the corresponding notebook and evaluate all cells
   by clicking on the button Run all.
2. To regenerate the simulation points, evaluate `MonteCarlo-OP-ASER.nb` and
   replace the simulation values in `OP-plot.nb` and `ASER-plot.nb` with
   the new output.
